# Background Sleep Alarm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a sleep goal is reached, make the device actually alarm even if InnerU is backgrounded or killed — a repeated notification burst with a real alarm tone on iOS, and a genuine looping foreground-service alarm on Android — stopping (and ending the sleep session) when the user taps it, or after a 5-minute timeout (sound only).

**Architecture:** A new `SleepAlarmService` (Dart) is the only thing `sleep_tracker.dart` talks to (`arm()`/`disarm()`). It delegates the iOS path to new methods on the existing `FastingNotificationService` (burst of scheduled notifications with a custom alarm sound), and the Android path to a new `inneru/sleep_alarm` MethodChannel backed by a `BroadcastReceiver` + foreground `Service` with a looping `MediaPlayer`. A synthesized alarm-buzzer `.wav` (generated by a checked-in script, not sourced/downloaded) is bundled on both platforms. The old foreground-only mechanism (`_playCompletionAlarm`, `_sleepAlarmPlayer`, `_armGoalReachedAlarm`, `_goalReachedTimer`) is deleted.

**Tech Stack:** Flutter/Dart, `flutter_local_notifications` (already a dependency), Kotlin (Android native), Python 3 stdlib (`wave` module, no third-party deps) for sound synthesis.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-24-sleep-alarm-background-design.md`
- Alarm timeout: 5 minutes if the user never responds (iOS: ~11 notifications 28s apart; Android: 5 minutes of continuous looping sound). On timeout, sound stops but the sleep session is **not** auto-ended.
- Stopping the alarm (tap on either platform, or tapping "End Sleep" in-app) stops the sound **and** ends the sleep session immediately.
- No iOS critical-alerts entitlement — out of scope, not pursued.
- Package name: `com.valenin.inneru`. `MainActivity.kt` at `android/app/src/main/kotlin/com/valenin/inneru/MainActivity.kt`.
- The alarm sound must NOT reuse any existing ambient asset (`Night_Firepit.mp3`, `Ocean_Waves.mp3`, `Rain_Sounds.mp3`, `Forest_Birds.mp3`) — it must be a distinct, synthesized alarm-buzzer tone.
- Native Android/iOS platform behavior (foreground service audio actually looping, notifications actually firing while backgrounded/killed, cold-start tap routing) is **not** verifiable by `flutter test` — each such task ends with manual device-verification steps instead of an automated test, consistent with this codebase's existing testability boundary for other native-plugin-backed code.

- [ ] **Step 1: Write the synthesis script**

Create `tool/generate_sleep_alarm_sound.py`:

```python
#!/usr/bin/env python3
"""Generates a synthesized alarm-clock buzzer tone as a loopable WAV file.

Deliberately does NOT reuse or download any existing audio -- this repo's
other audio assets (Night_Firepit.mp3, Ocean_Waves.mp3, Rain_Sounds.mp3,
Forest_Birds.mp3) are calm ambient/meditation sounds and are wrong for an
urgent wake-up alarm. This generates a distinct tone instead.
"""
import math
import struct
import wave

SAMPLE_RATE = 44100
AMPLITUDE = 0.6  # of full scale, to avoid clipping distortion
FADE_SAMPLES = 200  # ~4.5ms fade in/out per beep, avoids clicking


def _tone(freq_hz: float, duration_s: float) -> list[float]:
    total = int(SAMPLE_RATE * duration_s)
    samples = []
    for i in range(total):
        t = i / SAMPLE_RATE
        value = AMPLITUDE * math.sin(2 * math.pi * freq_hz * t)
        if i < FADE_SAMPLES:
            value *= i / FADE_SAMPLES
        elif i > total - FADE_SAMPLES:
            value *= (total - i) / FADE_SAMPLES
        samples.append(value)
    return samples


def _silence(duration_s: float) -> list[float]:
    return [0.0] * int(SAMPLE_RATE * duration_s)


def build_clip() -> list[float]:
    # Classic three-beep alarm cadence, the third beep pitched up for
    # urgency, totalling exactly 2.0s so it loops seamlessly.
    samples: list[float] = []
    samples += _tone(1000, 0.20)
    samples += _silence(0.10)
    samples += _tone(1000, 0.20)
    samples += _silence(0.10)
    samples += _tone(1300, 0.30)
    samples += _silence(1.10)
    return samples


def write_wav(path: str, samples: list[float]) -> None:
    with wave.open(path, "w") as wav_file:
        wav_file.setnchannels(1)
        wav_file.setsampwidth(2)  # 16-bit
        wav_file.setframerate(SAMPLE_RATE)
        frames = b"".join(
            struct.pack("<h", max(-32768, min(32767, int(s * 32767))))
            for s in samples
        )
        wav_file.writeframes(frames)


if __name__ == "__main__":
    write_wav("assets/audio/sleep_alarm.wav", build_clip())
    print("Wrote assets/audio/sleep_alarm.wav")
```

```dart
    required DateTime wakesAt,
    required int goalHours,
  }) async {
    await initialize();
    await cancelSleepAlarmBurst();

    final schedule = computeSleepAlarmBurstSchedule(wakesAt: wakesAt);
    final details = NotificationDetails(
      android: AndroidNotificationDetails(

        'Sleep wake alarm',
        channelDescription: _sleepWakeChannelDescription,
        importance: Importance.max,
        priority: Priority.high,

        categoryIdentifier: sleepAlarmCategoryId,
      ),
    );

    for (var i = 0; i < schedule.length; i++) {
      final fireTime = schedule[i];
      if (!fireTime.isAfter(DateTime.now())) continue;

      try {
        await _notifications.zonedSchedule(
          id: sleepAlarmBurstBaseId + i,
          title: 'Wake up',
          body: 'Your $goalHours-hour sleep goal is complete.',
          scheduledDate: tz.TZDateTime.from(fireTime, tz.local),
          notificationDetails: details,
          androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
          matchDateTimeComponents: null,
          payload: sleepAlarmPayload,
        );
      } catch (error) {
        debugPrint(
          'Exact sleep alarm burst scheduling failed for index $i, retrying inexact: $error',
        );
        await _notifications.zonedSchedule(
          id: sleepAlarmBurstBaseId + i,
          title: 'Wake up',
          body: 'Your $goalHours-hour sleep goal is complete.',
          scheduledDate: tz.TZDateTime.from(fireTime, tz.local),
          notificationDetails: details,
          androidScheduleMode: AndroidScheduleMode.inexactAllowWhileIdle,
          matchDateTimeComponents: null,
          payload: sleepAlarmPayload,
        );
      }
    }
  }

  Future<void> cancelSleepAlarmBurst() async {
    await initialize();
    for (var i = 0; i < sleepAlarmBurstCount; i++) {
      await _notifications.cancel(id: sleepAlarmBurstBaseId + i);
    }
  }
```

```kotlin
package com.valenin.inneru

import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import androidx.core.content.ContextCompat

/** Fired by AlarmManager at the user's calculated wake time; starts the
 * foreground service that actually plays the looping alarm sound. */
class SleepAlarmReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val serviceIntent = Intent(context, SleepAlarmForegroundService::class.java)
        serviceIntent.putExtra(
            SleepAlarmForegroundService.EXTRA_GOAL_HOURS,
            intent.getIntExtra(SleepAlarmForegroundService.EXTRA_GOAL_HOURS, 0),
        )
        ContextCompat.startForegroundService(context, serviceIntent)
    }
}
```

- [ ] **Step 3: Create the foreground service**

Create `android/app/src/main/kotlin/com/valenin/inneru/SleepAlarmForegroundService.kt`:

```kotlin
package com.valenin.inneru

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.app.Service
import android.content.Context
import android.content.Intent
import android.media.AudioAttributes
import android.media.MediaPlayer
import android.os.Build
import android.os.Handler
import android.os.IBinder
import android.os.Looper
import androidx.core.app.NotificationCompat

/** Plays a looping alarm sound and shows a full-screen, non-dismissable
 * notification until the user taps it, the app tells it to stop (End Sleep
 * tapped in-app), or 5 minutes pass with no response. */
class SleepAlarmForegroundService : Service() {
    companion object {
        const val EXTRA_GOAL_HOURS = "goal_hours"
        const val ACTION_STOP = "com.valenin.inneru.action.STOP_SLEEP_ALARM"
        const val EXTRA_STOP_TAPPED_BY_USER = "stop_tapped_by_user"
        private const val CHANNEL_ID = "sleep_alarm_service_channel"
        private const val NOTIFICATION_ID = 7200
        private const val TIMEOUT_MILLIS = 5 * 60 * 1000L
    }

    private var mediaPlayer: MediaPlayer? = null
    private val stopHandler = Handler(Looper.getMainLooper())
    private val timeoutRunnable = Runnable { stopSelfAndService(tappedByUser = false) }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        if (intent?.action == ACTION_STOP) {
            stopSelfAndService(tappedByUser = true)
            return START_NOT_STICKY
        }

        val goalHours = intent?.getIntExtra(EXTRA_GOAL_HOURS, 0) ?: 0
        startForeground(NOTIFICATION_ID, buildNotification(goalHours))
        startLoopingSound()
        stopHandler.postDelayed(timeoutRunnable, TIMEOUT_MILLIS)
        return START_STICKY
    }

    private fun startLoopingSound() {
        mediaPlayer?.release()
        val player = MediaPlayer.create(this, R.raw.sleep_alarm)
        player.isLooping = true
        player.setAudioAttributes(
            AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_ALARM)
                .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                .build(),
        )
        player.start()
        mediaPlayer = player
    }

    private fun buildNotification(goalHours: Int): Notification {
        val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val channel = NotificationChannel(
                CHANNEL_ID,
                "Sleep alarm",
                NotificationManager.IMPORTANCE_HIGH,
            ).apply { description = "Alerts you when your sleep goal is reached." }
            manager.createNotificationChannel(channel)
        }

        val stopServiceIntent = Intent(this, SleepAlarmForegroundService::class.java).apply {
            action = ACTION_STOP
        }
        val stopPendingIntent = PendingIntent.getService(
            this,
            0,
            stopServiceIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )

        val launchIntent = (packageManager.getLaunchIntentForPackage(packageName) ?: Intent())
            .apply {
                action = ACTION_STOP
                putExtra(EXTRA_STOP_TAPPED_BY_USER, true)
                flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TOP
            }
        val contentPendingIntent = PendingIntent.getActivity(
            this,
            0,
            launchIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )

        return NotificationCompat.Builder(this, CHANNEL_ID)
            .setSmallIcon(R.mipmap.launcher_icon)
            .setContentTitle("Wake up")
            .setContentText("Your $goalHours-hour sleep goal is complete.")
            .setPriority(NotificationCompat.PRIORITY_MAX)
            .setCategory(NotificationCompat.CATEGORY_ALARM)
            .setFullScreenIntent(contentPendingIntent, true)
            .setContentIntent(contentPendingIntent)
            .setOngoing(true)
            .setAutoCancel(false)
            // Stopping the sound alone (without opening the app) still uses
            // the service-only PendingIntent; opening the app (tapping the
            // notification body) also ends the sleep session via MainActivity.
            .addAction(0, "Stop sound", stopPendingIntent)
            .build()
    }

    private fun stopSelfAndService(tappedByUser: Boolean) {
        stopHandler.removeCallbacks(timeoutRunnable)
        mediaPlayer?.stop()
        mediaPlayer?.release()
        mediaPlayer = null
        stopForeground(STOP_FOREGROUND_REMOVE)
        stopSelf()
    }
```

Two different delivery paths are needed for the "stop tapped" signal, because they have different timing guarantees:
- **Cold start** (`onCreate`, app was fully terminated): the Dart side hasn't necessarily registered a handler for this channel yet by the time `onCreate` runs (Dart's `main()` does async setup first), so pushing immediately via `invokeMethod` here could be silently dropped. This case sets the `pendingSleepAlarmStopSignal` flag instead, for Dart to *poll* via `consumePendingStopSignal` once it's ready (see Task 4/5).

```dart
import 'dart:async';
import 'dart:io';

import 'package:flutter/services.dart';
import 'package:selfcare_projects/src/services/notifications/fasting_notification_service.dart';

class SleepAlarmService {
  SleepAlarmService._();

  static final SleepAlarmService instance = SleepAlarmService._();

  static const MethodChannel _androidChannel =
      MethodChannel('inneru/sleep_alarm');

  final _stoppedController = StreamController<void>.broadcast();
  StreamSubscription<void>? _iosStoppedSubscription;
  bool _pendingStopSignalConsumedAtLaunch = false;
  bool _androidChannelWired = false;

  /// Fires whenever the alarm was stopped by the user tapping it (on either
  /// platform) -- callers should react by ending the sleep session.
  Stream<void> get onAlarmStoppedByUser => _stoppedController.stream;

  void _ensureIOSListenerWired() {
    _iosStoppedSubscription ??=
        FastingNotificationService.instance.onSleepAlarmStopped.listen((_) {
      _pendingStopSignalConsumedAtLaunch = true;
      _stoppedController.add(null);
    });
  }

  /// Registers the handler that receives the *warm* push from
  /// `MainActivity.onNewIntent` (see Task 3). The cold-start case doesn't
  /// come through this handler at all -- it's discovered by polling
  /// `consumePendingStopSignal` instead, since native can't reliably push
  /// before this handler has been registered.
  void _ensureAndroidChannelWired() {
    if (_androidChannelWired) return;
    _androidChannelWired = true;
    _androidChannel.setMethodCallHandler((call) async {
      if (call.method == 'sleepAlarmStoppedByUser') {
        _pendingStopSignalConsumedAtLaunch = true;
        _stoppedController.add(null);
      }
      return null;
    });
  }

  Future<void> arm({
    required DateTime wakesAt,
    required int goalHours,
  }) async {
    if (Platform.isAndroid) {
      _ensureAndroidChannelWired();
      await _androidChannel.invokeMethod<void>('armSleepAlarm', {
        'triggerAtMillis': wakesAt.millisecondsSinceEpoch,
        'goalHours': goalHours,
      });
      return;
    }

    if (Platform.isIOS) {
      _ensureIOSListenerWired();
      await FastingNotificationService.instance.scheduleSleepAlarmBurst(
        wakesAt: wakesAt,
        goalHours: goalHours,
      );
    }
  }

  Future<void> disarm() async {
    if (Platform.isAndroid) {
      _ensureAndroidChannelWired();
      await _androidChannel.invokeMethod<void>('disarmSleepAlarm');
      return;
    }

    if (Platform.isIOS) {
      await FastingNotificationService.instance.cancelSleepAlarmBurst();
    }
  }

  /// Call once at app startup to detect a cold start caused by tapping the
  /// sleep alarm notification/alarm screen, since that case can't be
  /// delivered as a live callback the way a warm resume can, on either
  /// platform. Sets the [consumeLaunchStopSignal] latch in addition to
  /// emitting on [onAlarmStoppedByUser], so a listener that subscribes
  /// *after* this already ran (e.g. a screen the user navigates to later)
  /// can still notice it happened.
  Future<void> checkPendingStopSignalOnLaunch() async {
    if (Platform.isAndroid) {
      _ensureAndroidChannelWired();
      final hadSignal = await _androidChannel.invokeMethod<bool>(
        'consumePendingStopSignal',
      );
      if (hadSignal == true) {
        _pendingStopSignalConsumedAtLaunch = true;
        _stoppedController.add(null);
      }
      return;
    }

    if (Platform.isIOS) {
      // _ensureIOSListenerWired's callback already sets the latch and emits
      // on _stoppedController, so checkLaunchNotification firing a matching
      // event is sufficient -- no separate handling needed here.
      _ensureIOSListenerWired();
      await FastingNotificationService.instance.checkLaunchNotification();
    }
  }

  /// True exactly once, the first time it's read after
  /// [checkPendingStopSignalOnLaunch] found a pending stop signal. Lets a
  /// listener that subscribes to [onAlarmStoppedByUser] after that already
  /// ran still notice it happened.
  bool consumeLaunchStopSignal() {
    final value = _pendingStopSignalConsumedAtLaunch;
    _pendingStopSignalConsumedAtLaunch = false;
    return value;
  }
}
```
